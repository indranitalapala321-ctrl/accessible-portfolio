Accessible Portfolio Website

Technologies: Semantic HTML5, ARIA, CSS, Keyboard Accessibility, Screen Reader Support

Accessibility Features Implemented:

  • Skip to content link for keyboard users
  • All images with alt text, all interactive elements keyboard focusable
  • ARIA roles: banner, navigation, main, contentinfo
  • Color contrast ratio 7:1, focus indicators 3px outline
  • Semantic headings structure (h1-h3) for screen readers

Result: Lighthouse Accessibility Score 98/100
